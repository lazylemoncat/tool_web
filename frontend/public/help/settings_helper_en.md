# Settings Help

## Feature Groups

Settings manages account options, appearance, language and region, notification placeholders, and data import/export.

## Account Settings

### Account Summary

- View the current account.
- Open password management and account deletion pages.

### Change Password

1. Open **Settings > Account**.
2. Click **Manage Password**.
3. Enter old password, new password, and confirmation.
4. Save.

### Delete Account

1. Open **Settings > Account**.
2. Go to account deletion.
3. Enter your password as requested.
4. Confirm deletion.

Account deletion permanently removes account data.

## Appearance

### Built-in Themes

- **Light**: for bright environments.
- **Dark**: for low-light environments.
- **Matcha**: built-in soft theme.
- **System**: follows OS preference.

### Custom Themes

1. Open **Settings > Appearance**.
2. Click **Manage Custom Themes**.
3. Download the template or upload a theme file.
4. Preview the theme.
5. Apply it to your account.

Custom themes support color variables, page-level styling, custom buttons, and script extensions.

### Revert To Default

- Revert clears the active custom theme.
- The app returns to a built-in theme.

## Language And Region

- Supports Chinese and English.
- Interface text updates immediately after switching.
- Help content loads the selected language.

## Notifications

- Notification settings are currently a placeholder.
- They can later support reminders, due tasks, and budget alerts.

## Data Management

### Export Data

- Use **Settings > Data** to export.
- Data is exported as JSON.
- Use this before backup or migration.

### Import Data

- Select a JSON file in **Settings > Data**.
- Import restores existing data.
- Only import files from trusted sources.

## Recommended Use

- Download the default theme template before editing a custom theme.
- Export data regularly.
- Confirm login state after changing password.
