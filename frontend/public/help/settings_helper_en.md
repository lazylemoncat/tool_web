# Settings

## Default Task Filter

Controls which tasks are shown by default:
- **All**: Show all tasks
- **Active**: Show only incomplete tasks
- **Completed**: Show only completed tasks

## Theme

### Base Themes
- **Light**: Light background, suitable for daytime
- **Dark**: Dark background, eye-friendly mode
- **System**: Automatically follow system theme

### Custom Themes
1. Click **Download Template** to get the current theme's JSON file
2. Edit the CSS variable values in the file (colors, spacing, etc.)
3. Click **Upload Theme File** to select your modified JSON file
4. Click **Apply** in the **My Themes** list to use it
5. Deleting an active theme will fall back to system default

## Language

Supports Chinese and English. Changes take effect immediately.
