# 账号认证帮助

## 功能分类

账号认证负责注册, 登录, 会话保持, 退出登录, 修改密码和注销账号.

## 注册账号

1. 打开登录页面.
2. 点击 **注册** 切换到注册模式.
3. 输入用户名和密码.
4. 点击 **注册**.

注册成功后会自动登录.

## 登录

1. 打开登录页面.
2. 输入用户名和密码.
3. 可选择 **记住我**.
4. 点击 **登录**.

登录成功后进入应用首页. 后续 API 请求会自动携带认证 token.

## 记住我

- 勾选后会保留登录状态.
- 不勾选时, 会话更偏向当前浏览器会话使用.

## 显示和隐藏密码

- 点击密码输入框旁的眼睛按钮可切换密码可见性.
- 该操作只影响当前输入框显示, 不会改变密码内容.

## 退出登录

1. 在应用中点击用户入口或退出按钮.
2. 确认退出.
3. 退出后会返回登录状态.

## 修改密码

1. 进入 **设置 > 账号 > 修改密码**.
2. 输入旧密码.
3. 输入新密码并再次确认.
4. 点击保存.

如果两次新密码不一致, 页面会显示错误提示.

## 注销账号

1. 进入 **设置 > 账号 > 注销账号**.
2. 阅读风险提示.
3. 输入密码确认身份.
4. 点击确认注销.

注销账号会永久删除账户及相关数据, 操作不可恢复.

## 安全说明

- 密码由后端加密存储.
- 登录后使用 JWT token 识别身份.
- 除认证接口外, API 请求都需要有效 token.
- 前端会自动处理 token 附加, 用户不需要手动配置.
