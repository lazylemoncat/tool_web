# Todo Help

## Feature Groups

Todo manages tasks, folders, subtasks, tags, search, filters, bulk actions, and ordering. Open it from the home task area or `/todo`.

## Task Management

### Create A Task

1. Click **+ New Task** in the toolbar.
2. Enter a task title. The title is required.
3. Optionally choose a folder, priority, due date, note, tags, and recurrence rules.
4. Click **Confirm** to save.

### Edit A Task

1. Click the edit action on a task row.
2. Change title, folder, priority, due date, note, tags, or recurrence rules.
3. Click **Save**.

### Complete Or Reopen

- Click the circular checkbox on the left of a task.
- Completed tasks use completed styling.
- Use status filters to show all, active, or completed tasks.

### Delete A Task

1. Click the delete action on a task row.
2. Review the confirmation dialog.
3. Click **Confirm**. Deleted tasks cannot be restored.

## Subtasks

### Create Subtasks

1. Click the add-subtask action on a task.
2. Fill in the subtask form.
3. Save it under the parent task.

### Work With Subtasks

- Parent tasks show subtask completion counts.
- Click the count to open the subtask drawer.
- Subtasks support completion, editing, deletion, and sorting.

## Folders

### Folder Navigation

- The left sidebar shows all tasks and the folder tree.
- Click **All** to view every task.
- Click a folder to view tasks in that folder.

### Create And Manage Folders

- Click **New Folder** to create a root folder.
- Click the add button on a folder to create a child folder.
- Rename and delete folders from the sidebar.
- Delete actions show a confirmation with impact details.

### Folder Ordering

- Drag the folder handle to reorder folders.
- Child folders can be reordered within the same level.

## Tags

### Add Tags

- Select or create tags in the task form.
- A task can have multiple tags.

### Filter By Tags

- Use the tag dropdown in the toolbar.
- Tag filters can be combined with search, status, and priority filters.

## Search And Filters

### Search

- Type keywords in the search box to match task titles.
- Press `/` to focus the search box.

### Status Filters

- **All**: show every task.
- **Active**: show incomplete tasks.
- **Completed**: show completed tasks.

### Priority Filters

- Filter by all, high, medium, or low priority.
- Priority should represent execution order or urgency.

## Bulk Actions

1. Click **Multi-select**.
2. Select tasks.
3. Complete or delete selected tasks.
4. Bulk delete uses a confirmation dialog.

## Drag Sorting

- Task lists support drag sorting.
- Drag from the handle on the left side of the row.
- Ordering is saved.
- Subtask lists support the same behavior.

## Keyboard Shortcuts

- `N`: create a task.
- `/`: focus search.
- `Esc`: close the task form.

## Recommended Use

- Use folders for projects or long-lived categories.
- Use tags for context, temporary states, or cross-cutting labels.
- Use priority for execution order.
- Use subtasks to break down complex work.
