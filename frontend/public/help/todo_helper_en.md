# Todo Feature

## Creating Tasks

Click **+ New Task** button at the top right and fill in:

- **Task Name**: Required, describe what you need to do
- **Folder**: Optional, categorize tasks into folders
- **Priority**: High / Medium / Low, help prioritize important tasks
- **Due Date**: Optional, set a reminder date
- **Note**: Optional, add extra notes
- **Tags**: Optional, type tag name and press Enter. Multiple tags supported

## Editing Tasks

1. Click the ✎ button on the right of a task to open the edit modal
2. Or click the task title to enter inline editing mode
3. Press Enter to save changes

## Subtasks

- Click the ＋ button to add subtasks
- Subtasks support unlimited nesting
- Click the subtask count hint (e.g., ▸ 2/5) to expand or collapse
- Subtasks also support drag-and-drop sorting

## Drag and Drop

- Press and hold any part of a task row, drag 5+ pixels to reorder
- On mobile, long-press 200ms then drag
- Folders and subtask lists also support drag-and-drop

## Search and Filter

- Use the search bar to filter by title
- Use status buttons (All / Active / Completed)
- Use priority buttons to filter
- Use the tag dropdown to filter by tag
- Multiple filters can be combined

## Completing Tasks

Click the circle on the left of a task to toggle completion. Completed tasks show a strikethrough title.
