# 设置说明

## 默认任务筛选

控制进入首页时的默认任务展示状态：
- **全部**：显示所有任务
- **未完成**：只显示未完成的任务
- **已完成**：只显示已完成的任务

## 主题

### 基础主题
- **浅色**：浅色背景，适合白天使用
- **深色**：深色背景，护眼模式
- **跟随系统**：自动跟随系统主题设置

### 自定义主题
1. 点击 **下载默认模板** 获取当前主题的 JSON 文件
2. 修改文件中的 CSS 变量值（颜色、间距等）
3. 点击 **上传主题文件** 选择修改后的 JSON 文件
4. 在 **我的主题** 列表中点击 **应用** 即可使用
5. 删除主题时如果该主题正在使用中，会自动切换回系统默认

## 语言

支持中文和 English，切换后即时生效。
