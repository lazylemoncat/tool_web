# 设置帮助

## 功能分类

设置用于管理账号, 外观主题, 语言地区, 通知占位和数据导入导出.

## 账号设置

### 账号概览

- 查看当前登录账号.
- 进入密码管理和注销账号页面.

### 修改密码

1. 打开 **设置 > 账号**.
2. 点击 **管理密码**.
3. 输入旧密码, 新密码和确认密码.
4. 保存.

### 注销账号

1. 打开 **设置 > 账号**.
2. 进入注销账号页面.
3. 按页面提示输入密码确认.
4. 确认后账号数据将被永久删除.

## 外观设置

### 基础主题

- **浅色**: 适合明亮环境.
- **深色**: 适合暗光环境.
- **抹茶拿铁**: 内置柔和主题.
- **跟随系统**: 自动使用系统主题偏好.

### 自定义主题

1. 打开 **设置 > 外观**.
2. 点击 **管理自定义主题**.
3. 下载默认模板或上传主题文件.
4. 预览主题效果.
5. 应用到当前账号.

自定义主题支持颜色变量, 页面级样式, 自定义按钮和脚本扩展.

### 恢复默认

- 点击恢复默认可清除当前自定义主题.
- 清除后会回到内置主题.

## 语言和地区

- 支持中文和 English.
- 切换语言后界面文案即时更新.
- 帮助文档会加载对应语言版本.

## 通知

- 通知设置目前是占位入口.
- 后续可用于提醒, 到期任务和预算预警.

## 数据管理

### 导出数据

- 在 **设置 > 数据管理** 点击导出.
- 数据以 JSON 格式导出.
- 适合备份或迁移前保存快照.

### 导入数据

- 在 **设置 > 数据管理** 选择 JSON 文件导入.
- 导入用于恢复已有数据.
- 导入前应确认文件来源可信.

## 使用建议

- 修改主题前先下载默认模板作为参考.
- 定期导出数据作为备份.
- 修改密码后重新确认登录状态.
